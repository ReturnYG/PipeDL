# PipeDL v0.3.1

PipeDL 桌面端迁移为 **Tauri 2 + Rust + Web UI + HTTP API**，应用本身不再依赖 Python。

- 成功实验使用绿色勾号、绿色卡片边框；失败实验使用红色叉号、红色卡片背景和状态标签。
- 历史页新增「删除所有已完成」按钮。二次确认后清理所有分页中的成功实验及日志，失败、停止、取消和队列中的记录保留。
- 界面通过 SSE 更新状态，日志增量读取；进程控制和数据库操作移出界面线程。
- 保留 PowerShell、CMD、Bash、WSL 运行环境；统一使用有鉴权的 HTTP API 提交和管理实验，移除独立控制 CLI。
- 修复 Windows 中文日志、CMD 引号路径、WSL 进程组控制；关闭窗口隐藏到托盘，退出前保护正在运行的任务。
- 添加迁移备份、异常任务隔离，以及 Linux/Windows 核心和界面检查。

## 下载

Windows x64：使用 `PipeDL_0.3.1_x64-setup.exe` 安装，或直接运行 `PipeDL.exe`。`SHA256SUMS` 提供校验值。需要 WebView2，安装程序会在缺少时引导安装。当前产物未做代码签名。

## 从旧版升级

1. 完成或停止正在运行的实验，并完全退出旧版。
2. 备份 `%LOCALAPPDATA%\PipeDL`，特别是数据库和日志。**旧 Inno Setup 卸载程序会删除运行数据，请勿在备份前卸载旧版。**
3. 新版使用相同的默认数据目录，并在迁移旧库前自动创建数据库备份。自定义数据路径请查阅 `docs/migration.md`。
4. 脚本改为使用 HTTP API，并提供 `Authorization: Bearer <token>`；凭据可在设置中复制。独立 `pipedl_cli` 不再随新版分发。

设置中的更新入口打开 GitHub Releases；尚未启用签名自动更新。Linux 核心和浏览器界面已有测试，Linux 原生桌面窗口尚未完成本地运行验证。
